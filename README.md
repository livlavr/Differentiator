# Differentiator
**Дифференциатор** — программа считывает математическое выражение из текстового файла, вычисляет его производную, упрощает результат и создает PDF-документ с пошаговым описанием процесса дифференцирования и забавными комментариями :)

> [!WARNING]
> Если вы проходили обучение в советских яслях, то эта программа вам ничем не поможет, вы итак можете продифференцировать любое выражение в уме.

## Установка и запуск

1. Склонируйте репозиторий:
    ```sh
    git clone git@github.com:livlavr/Differentiator.git
    ```
2. Подгрузите сабмодули:
    ```sh
    git submodule update --init --remote --recursive
    ```
3. Убедитесь, что у вас установлена утилита [Graphviz](https://graphviz.org/) для визуализации дерева.
4. Установите дистрибутив LaTeX (например, [TeX Live](https://www.tug.org/texlive/)) для генерации PDF. Если нет желания заморачиваться с локальными компиляторами, то добро пожаловать в [Overleaf](https://www.overleaf.com/project)
5. Перейдите в директорию проекта и соберите его:
   ```sh
   make all
   ./build/Differentiator
   ```
6. или два этих шага за одну команду:
    ```sh
    make run
    ```

## Использование

1. Подготовьте текстовый файл с математическим выражением, `LatexSource/DiffSource.txt`. Пример содержимого:
```5*sin(10*x^3) + cos(20*x - 1)```
2. Запустите программу (см [Установка и запуск](#установка-и-запуск))
3. Программа сгенерирует PDF-файл `Latex/diff.pdf` с пошаговым описанием дифференцирования и упрощения.

Для **визуализации дерева** выражения используйте функции `TreeDump(&tree) и OpenDump(&tree)`, для того, чтобы взаимодействовать с dump-ом дерева выражений. Можете запустить проект сразу после клонирования - в 'main.cpp' уже включены данные функции

## Описание

Программа принимает **математическое выражение**, строит дерево операций, выполняет **дифференцирование** и упрощение, в это время записывает все шаги в генерируемый **LaTeX** файл, который по окончанию генерации компилируется в **pdf**. *Надеюсь не утомил подробностями.*

Как было понятно из описания процесс дифференцирования включает **три ключевых этапа:**
1. Построение *дерева выражения*
2. Рекурсивное дифференцирование с использованием кодогенерации
3. Упрощение результата.
> [!TIP]
> Дерево выражения можно визуализировать с помощью утилиты Graphviz. `TreeDump(&tree) и OpenDump(&tree)`

## Возможности

- **Парсинг выражений:** Разбора входного выражения и построения дерева приоритетов операций.
- **Визуализация дерева:** Дерево выражения можно визуализировать. При вызове функции `TreeDump(&tree)` dump-ы дерева будут конкатинироваться в один html файл.
- **Дифференцирование:** Рекурсивное вычисление производной.
- **Упрощение:** После дифференцирования итоговое выражение упрощается для улучшения читаемости.
- **Документация:** Все шаги процесса, включая дифференцирование и упрощение, записываются в PDF-файл с пояснениями.

## Подробнее про дифференцирование

- **Рекурсивное дифференцирование:**
   - Дерево обходит рекурсивно, применяя правила дифференцирования для каждого узла.
   - Правила задаются через кодогенерацию в файле `codegen.def`.

![Пример использования кодгена](img/Screenshot%202025-04-14%20at%2023.08.42.png)

Для каждого оператора (например, `ADD`, `MUL`, `POW`) определены правила вывода в LaTeX, вычисления, упрощения и дифференцирования.
Это нужно для того, чтобы не раздувать исходники большим количество if-ов или switch-ей. Обычно для кодогенерации используют `python`,
но так как проект был выполнен в рамках учебного курса по `C`, пришлось выкручиваться таким изящным образом.
Получилось достаточно читабельно и понятно, особенно в сравнении с версиями на свитчах.

Генерируемый PDF содержит все шаги с комментариями, что делает процесс наглядным.
